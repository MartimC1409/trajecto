# Registo de decisões de arquitetura (ADR)

Cada ADR descreve uma decisão importante: o contexto, a escolha feita, as consequências e as alternativas que ficaram de fora.

Estados possíveis:

- **Proposto:** aguarda confirmação.
- **Aceite:** decisão em vigor.
- **Substituído:** indica o ADR que o substitui.
